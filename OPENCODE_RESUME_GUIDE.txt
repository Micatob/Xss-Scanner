HOW TO CONTINUE A SESSION AFTER A SHUTDOWN
============================================
Option A (simplest -- uses the autosaved DB):
  Open a terminal in the project folder and run:
      opencode -s <sessionID>
  (or: opencode -c  to continue the most recent session in that folder)

Option B (restore from the per-folder JSON backup, if the DB is gone):
      opencode import <full path to opencode-backup-<sessionID>.json>
  then continue with the restored session.
